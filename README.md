# python-utils-12

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A lightweight, high-performance auto-clicker for Python designed to automate repetitive mouse actions with microsecond precision. It features a thread-safe programmatic interface and global system hotkeys to seamlessly integrate into gaming, quality assurance, or workflow automation pipelines.

## Features

- **Microsecond Precision:** Achieve up to 1000 clicks per second with minimal CPU overhead.
- **Global Hotkey Integration:** Instantly toggle clicking on/off from anywhere using customizable hotkeys (default is `F8`).
- **Human-Like Randomization:** Add adjustable micro-delays between clicks to simulate natural human interaction and bypass simple bot detection.
- **Multi-Button Support:** Native configuration for left, right, middle, and double-clicking actions.
